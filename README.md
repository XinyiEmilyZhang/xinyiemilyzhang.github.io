# Xinyi Zhang academic website

An AcademicPages-inspired Jekyll starter for GitHub Pages.

- Edit the homepage sections in `index.html`.
- The header, sidebar and footer are in `_layouts/default.html`.
- Edit the palette and layout in `assets/site.css`. The sidebar photo is in `assets/portrait.jpg`.

With Ruby and Bundler installed, run `bundle install` and `bundle exec jekyll serve` from this directory. The separate preview folder is a rendered snapshot. Open its index.html in a browser.

For GitHub Pages, use the contents of this folder as the source at the root of the repository and choose the intended branch under repository Settings → Pages. Keep .nojekyll absent so Pages renders Jekyll.

The homepage lists five publications and preprints. The coronary screening article uses its April 2026 issue year and notes its October 2025 online date. The Software section includes ripserr and links to its current CRAN release.

Academic sidebar layout inspired by https://stmcg.github.io/.
